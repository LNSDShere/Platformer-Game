  =====================================================
   N E O N   R U S H  -  2D Parkour Action Platformer
  =====================================================

  WHAT THIS IS
  ------------
  A complete action parkour game: 8 worlds, 43 levels,
  3 boss fights, unlockable abilities, medals and secrets.
  It runs 100% on your own computer. No internet needed,
  nothing to install, no account, no ads.

  HOW TO START (pick ONE)
  -----------------------
  Windows : double-click  "PLAY - WINDOWS.bat"
  Mac     : double-click  "PLAY - MAC.command"
             (first time only: right-click it -> Open)
  Linux   : double-click  "PLAY - LINUX.sh"
  Any PC  : or just double-click  "index.html"

  The game opens in your web browser (Chrome, Edge,
  Safari or Firefox). You do NOT need internet -
  the browser just acts as the game screen.
  Best experienced with sound ON and in FULLSCREEN
  (press F11 in the browser).

  IMPORTANT: keep this whole folder together.
  Do not delete or rename the "_next" folder or any files.

  CONTROLS
  --------
  Move .............. A / D  or  Left / Right arrows
  Jump (double too!)  SPACE / W / Up arrow
  Dash .............. SHIFT or X   (8 directions)
  Ground pound ...... S / Down arrow  (while in air)
  Wall jump ......... hold toward a wall, then jump
  Grapple .......... C or E   (when near a glowing node)
  Restart level ..... R
  Pause / menu ...... ESC

  Touch screen? On-screen buttons appear automatically.

  GOOD TO KNOW
  ------------
  - Progress saves automatically in the browser.
  - Jump on enemies' heads to squash them.
  - Green flags = checkpoints (safe respawn).
  - Grab all 3 shards in a level + beat the target time
    for a gold medal.
  - Abilities (dash, wall jump, pound, grapple) unlock
    as you progress through the worlds.
  - Aiming for 100%? That's easily 3-5 hours of play.

  ALREADY PLAYING? UPDATING TO A NEWER VERSION
  ---------------------------------------------
  DO NOT extract this zip into a new folder if
  you want to keep your progress. Instead:
  1. Open the folder where your current game is.
  2. Extract this new zip INTO THAT SAME folder
     (choose "overwrite/replace" when asked).
  3. Double-click PLAY again - same browser as
     before - and your progress is right there.
  Your save lives inside the browser you play in,
  so keep using the same browser (Chrome, Edge...)
  and the same folder, and nothing is ever lost.

  IF IT DOESN'T START
  -------------------
  1. Open it with Chrome or Edge (most reliable).
  2. Make sure you extracted the WHOLE zip folder
     before playing - don't run it from inside the zip.
  3. To reset your progress: in the game menu go to
     OPTIONS -> clear save data.

  Have fun. Go get that gold.
